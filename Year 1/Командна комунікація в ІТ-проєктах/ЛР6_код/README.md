# kn-26-1-lab6-array — обробка масиву (ЛР-6, варіант 4)

Команда: Бойчук А. А. (координатор), Вітер Н., Блохін В. О., Кащин С. Р.

Завдання: у масиві B з 14 елементів замінити від'ємні елементи на парних місцях
максимальним елементом масиву, а на непарних — максимальним серед від'ємних.

| Гілка | Автор | Зміст |
|---|---|---|
| main | Бойчук А. А. | базовий розв'язок, масив задано в коді |
| alt-data | Бойчук А. А. | набір даних без від'ємних елементів |
| feature/keyboard-input | Вітер Н. | a) введення розміру та елементів з клавіатури |
| feature/random-fill | Блохін В. О. | b) заповнення генератором випадкових чисел |
| feature/formatted-output | Кащин С. Р. | c) форматований вивід у рядок |
| feature/while-output | Бойчук А. А. | d) вивід масиву циклом while |

Збирання: `gcc -std=c11 -Wall -o main.exe main.c`

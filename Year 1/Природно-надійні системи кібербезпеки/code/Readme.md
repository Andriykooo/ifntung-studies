# Лабораторні роботи з курсу "Природно надійні системи кібербезпеки"

Цей репозиторій містить серію лабораторних робіт, присвячених реалізації різних нейромережевих архітектур (BAM, CMAC, SRN, GRU, LSTM, Attention) для задач шифрування та обробки послідовностей.

## ⚠️ Вимоги до середовища

Для запуску цих проєктів потрібна **дуже специфічна версія Python**, оскільки деякі оригінальні бібліотеки (`neupy`) застаріли, а новіші (`tensorflow`) мають суворі вимоги.

* **Python:** `3.9.x` (Обов'язково!)
* **Система:** Інструкція оптимізована для macOS (з Homebrew).

---

## 🚀 Налаштування середовища (з нуля)

Виконайте ці кроки у вашому терміналі, щоб налаштувати проєкт.

### 1. Клонування репозиторію

```bash
git clone [URL_ВАШОГО_РЕПОЗИТОРІЮ]
cd [НАЗВА_ПАПКИ_ПРОЄКТУ]
````

### 2. Встановлення Python 3.9 (якщо не встановлено)

Перевірте вашу версію: `python3 --version`. Якщо у вас не 3.9, встановіть її:

```bash
brew install python@3.9
```

### 3. Створення та активація віртуального середовища

Ми створимо віртуальне середовище (`venv`), використовуючи **саме** `python3.9`.

```bash
# Створення venv
python3.9 -m venv venv

# Активація venv
source venv/bin/activate
```

*(Після активації ви побачите `(venv)` на початку рядка у терміналі)*

### 4. Встановлення залежностей

У репозиторії має бути файл `requirements.txt`.

```bash
# Оновлення pip всередині venv
pip install --upgrade pip

# Встановлення всіх пакетів зі списку
pip install -r requirements.txt
```

### 5. Готово!

Тепер ваше середовище повністю налаштоване.

## 🏃‍♀️ Запуск лабораторних робіт

1.  Переконайтеся, що ваше середовище активоване (`source venv/bin/activate`).

2.  Скопіюйте код необхідної лабораторної роботи у ваш основний файл (наприклад, `main.py`).

3.  Запустіть файл:
    ```bash
    python3 <filename>.py
    ```

## 📄 Важливі примітки

* **Лабораторні роботи 1 та 2 (`neupy`)**: Оригінальна бібліотека `neupy` застаріла і несумісна з сучасними Mac (Apple Silicon) та версіями Python. Код у репозиторії для Лаб 1 та 2 є реалізацією на чистому `numpy`, яка обходить цю проблему.
* **`.gitignore`**: Файл `.gitignore` у цьому репозиторії вже налаштований, щоб ігнорувати папку `venv`. **Ніколи не додавайте папку `venv` до Git.**

# Репозиторій аспірантури ЧДТУ

## Опис
Цей репозиторій містить матеріали, пов'язані з аспірантурою в Черкаському державному технологічному університеті (ЧДТУ). Тут містяться звіти, дослідження, навчальні матеріали та інші ресурси.

## Корисні посилання
- [Офіційний сайт ЧДТУ](https://chdtu.edu.ua)
- [Сторінка аспірантури ЧДТУ](https://chdtu.edu.ua/science/postgraduate)
- [Moodle ЧДТУ](https://moodle.chdtu.edu.ua)
- [Розклад занять ЧДТУ](https://tt.chdtu.edu.ua/cgi-bin/timetable.cgi)

## Загальна інформація
- **Назва університету:** Черкаський державний технологічний університет (ЧДТУ)
- **Адреса:** бульвар Шевченка, 460, Черкаси, Україна
- **Група:** `A-F5-25` (Латинськими літерами)
- **Кафедра:** F5 - Кібербезпека та захист інформації
- **Спеціальність:** 125 - Кібербезпека
- **Факультет**: Факультет інформаційних технологій та кібербезпеки (Факультет інформаційних технологій і систем)

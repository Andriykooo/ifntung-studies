# Навчальний репозиторій ІФНТУНГ

## Опис
Цей репозиторій містить матеріали навчання в Івано-Франківському національному технічному університеті нафти і газу (ІФНТУНГ): лабораторні та практичні роботи, звіти, конспекти та інші ресурси.

## Корисні посилання
- [Офіційний сайт ІФНТУНГ](https://nung.edu.ua/)
- [Moodle ІФНТУНГ (дистанційне навчання)](https://dn.nung.edu.ua/)
- [Розклад занять](https://dekanat.nung.edu.ua/cgi-bin/timetable.cgi)

- **Студент:** Бойчук Андрій Анатолійович
- **Університет:** Івано-Франківський національний технічний університет нафти і газу (ІФНТУНГ)
- **Рік вступу:** 2026 (1 курс)
- **Група:** `КН-26-1`
